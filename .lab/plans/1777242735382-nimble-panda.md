## Module Specifications

### 1. Event Module
**Purpose:** Manage stadium events (football matches, concerts, etc.)

**Schema:**
- MySQL: `events` table (id, name, description, event_date, stadium_location, created_at)
- MongoDB: Event document (name, description, eventDate, stadiumLocation, createdAt)

**Endpoints:**
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /api/mysql/events | List all events |
| GET | /api/mysql/events/:id | Get event by ID |
| POST | /api/mysql/events | Create event |
| PUT | /api/mysql/events/:id | Update event |
| DELETE | /api/mysql/events/:id | Delete event |
| GET | /api/mongodb/events | List all events (MongoDB) |
| GET | /api/mongodb/events/:id | Get event by ID |
| POST | /api/mongodb/events | Create event |
| PUT | /api/mongodb/events/:id | Update event |
| DELETE | /api/mongodb/events/:id | Delete event |

---

### 2. Booking Module
**Purpose:** Links users to tickets they have purchased/booked

**Schema:**
- MySQL: `bookings` table (id, user_id, ticket_id, booking_date, status, total_price)
- MongoDB: Booking document (userId ref, ticketId ref, bookingDate, status, totalPrice)

**Relationships:**
- User 1:N Bookings
- Ticket 1:N Bookings
- Booking belongsTo User, belongsTo Ticket

**Endpoints:**
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /api/mysql/bookings | List all bookings |
| GET | /api/mysql/bookings/:id | Get booking by ID |
| GET | /api/mysql/bookings/user/:userId | Get bookings by user |
| POST | /api/mysql/bookings | Create booking |
| PUT | /api/mysql/bookings/:id | Update booking |
| DELETE | /api/mysql/bookings/:id | Delete booking |
| (Same for MongoDB) | | |

---

### 3. Stadium Module
**Purpose:** Stadium information and seat categories

**Schema:**
- MySQL: `stadiums` table (id, name, location, capacity, created_at)
- MongoDB: Stadium document (name, location, capacity, createdAt)

**Schema:**
- MySQL: `seat_categories` table (id, stadium_id, category_name, price_multiplier)
- MongoDB: SeatCategory embedded or separate collection

**Endpoints:**
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /api/mysql/stadiums | List all stadiums |
| GET | /api/mysql/stadiums/:id | Get stadium by ID |
| POST | /api/mysql/stadiums | Create stadium |
| PUT | /api/mysql/stadiums/:id | Update stadium |
| DELETE | /api/mysql/stadiums/:id | Delete stadium |
| GET | /api/mysql/stadiums/:id/seats | Get seat categories |
| POST | /api/mysql/stadiums/:id/seats | Add seat category |
| (Same for MongoDB) | | |

---

### 4. Payment Module (Optional)
**Purpose:** Track payment transactions for bookings

**Schema:**
- MySQL: `payments` table (id, booking_id, amount, payment_method, status, transaction_date)
- MongoDB: Payment document

## MySQL Table Creation Scripts

```sql
-- Events table
CREATE TABLE IF NOT EXISTS events (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  description TEXT,
  event_date DATETIME NOT NULL,
  stadium_location VARCHAR(255),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Bookings table
CREATE TABLE IF NOT EXISTS bookings (
  id INT AUTO_INCREMENT PRIMARY KEY,
  user_id INT NOT NULL,
  ticket_id INT NOT NULL,
  booking_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  status ENUM('pending', 'confirmed', 'cancelled') DEFAULT 'pending',
  total_price DECIMAL(10, 2) NOT NULL,
  FOREIGN KEY (user_id) REFERENCES users(id),
  FOREIGN KEY (ticket_id) REFERENCES tickets(id)
);

-- Stadiums table
CREATE TABLE IF NOT EXISTS stadiums (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  location VARCHAR(255),
  capacity INT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Seat categories table
CREATE TABLE IF NOT EXISTS seat_categories (
  id INT AUTO_INCREMENT PRIMARY KEY,
  stadium_id INT NOT NULL,
  category_name VARCHAR(100) NOT NULL,
  price_multiplier DECIMAL(4, 2) DEFAULT 1.00,
  FOREIGN KEY (stadium_id) REFERENCES stadiums(id)
);
```
