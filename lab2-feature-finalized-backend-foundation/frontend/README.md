# Stadium Booking Frontend

This is a Vite + React frontend scaffold for the Stadium Ticket Booking System.

Quick start:

1. cd frontend
2. npm install
3. npm run dev

Set API base URL via `VITE_API_BASE_URL` environment variable (e.g. `VITE_API_BASE_URL=http://localhost:5000/api/mysql`).

Copy `.env.example` to `.env` to override defaults locally.
